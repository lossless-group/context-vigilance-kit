# Brand icons

Generated with Ideogram v3 on 2026-10-08 as candidates for the plugin directory listing icon.
`.claude-plugin/icon.png` is woodcut variant 04, the only one shipped in the repo.

The candidates live on ImageKit, not in git: the plugin directory's security scan reads
printable byte runs in every shipped image, and large PNGs kept turning up chance matches
for shell commands. The lossless PNG originals are in git history at commit `3ccfe60`
(`splash/public/brand/Icon__Engineer-*--Variant-0N.png`).
