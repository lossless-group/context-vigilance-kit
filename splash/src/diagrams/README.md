# Diagrams

`recommended-flow.svg` is generated by [Archify](https://github.com/tt-a1i/archify), then lightly cleaned for the site. Don't hand-edit the SVG's layout; change the source and regenerate.

- **Source:** `recommended-flow.archify.json` (an Archify workflow).
- **Regenerate:** `node <archify>/bin/archify.mjs finalize workflow recommended-flow.archify.json out.html --quality showcase --json`, then copy the `<svg>…</svg>` out of `out.html`.
- **Clean-up applied:** crop `viewBox` to the lanes plus a margin (`30 40 904 460`; the hidden legend leaves empty space below); remove the grid `<pattern>` and its background `<rect>`; prefix marker IDs with `cvflow-` (`arrowhead` → `cvflow-arrowhead`, including `url(#…)` references); rename the title/desc IDs to `cvflow-title` / `cvflow-desc`; write a real `<desc>`; add `class="cvflow"` to the `<svg>`.
- **Colors** come from `src/components/RecommendedFlow.astro`, which maps Archify's classes (`c-frontend`, `t-primary`, `a-emphasis`, …) to the site's theme tokens, so the diagram follows light, dark, and vibrant modes.
