# Context Vigilance Kit

> {{SITE_NAME}}

Treat context with the same vigilance as code: versioned, reviewed, cross-linked. The Context Vigilance Kit is a plugin for coding agents (Claude Code natively; any Agent Skills tool by copying the skills) that gives a repo a `context-v/` folder of living docs and seven workflow skills: init, new, kickoff, prep, implement, loop, reflect. MPL-2.0; what users make with it is theirs.
