# changelog

A dated ship log: one entry per coherent piece of work that landed, written so someone who's never seen the project understands what changed for them.

- **Filename:** `YYYY-MM-DD_NN.md` (`NN` is `01`, `02`… for that day).
- **Shape:** frontmatter, then *Why Care?*, *What's New?*, *Known Gotchas*, *What's Next?*. The `reflect` skill writes these for you.
- **The rule that matters:** a short, true entry beats a polished one that never gets written.
