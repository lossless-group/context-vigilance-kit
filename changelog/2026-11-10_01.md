## Why Care?

Plenty of web apps are run by someone who isn't a developer: a founder, a club organizer, a client. When they want "a real app on people's phones", the work is less about code than about Apple and Google accounts, signing keys, test builds, store rules and yearly upkeep. This skill lets an agent do the technical part and teach the rest, one visible step at a time.

## What's New?

- **`mobile-x-platform-w-tauri` skill:** wraps a hosted web app in a Tauri 2 shell that opens the live site, for iPhone and Android.
  - Starts by collecting the project's facts (live and test URLs, the permanent app ID, who owns the store accounts, what data must never be touched by a test).
  - Rules the agent never breaks: no store upload without the owner's yes to that build, no signing secrets in git, no test writes against production.
  - The commands, a testing ladder from desktop window to real users, a device checklist, a release checklist, when a new build is (and isn't) needed, and common errors with fixes.
  - Says plainly what a shell can't do (offline, push, public App Store approval) and when to move to a bundled app on an API instead.
- **An owner's guide template** (`references/owner-guide.md`): the step-by-step guide the agent writes into the project's `context-v/docs/` for the owner to follow.
